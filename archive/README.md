# Archive

This directory preserves earlier project branches and exploratory work that are **not the current maintained COSMOS Music application**.

Nothing here is the recommended installation path. The active product lives at [`../COSMOS_MUSIC_SUITE/`](../COSMOS_MUSIC_SUITE/).

## `legacy-demos/`
Earlier simulation, VJ and cosmic-synapse demonstration folders.

## `experiments/`
Exploratory AI and consciousness-named tests. The historical filenames are preserved for lineage. Their names should not be read as evidence that consciousness was established or measured.

## `legacy-music/`
Earlier music-project ancestry that predates the organized COSMOS Music Suite.

## `project-notes/`
Superseded PR prompts and implementation instructions. They are retained so the development history remains auditable, but they are not current contributor instructions.

## Why archive instead of delete?

The repository is part software project and part engineering lineage. Moving obsolete material out of the main path keeps the current product understandable without erasing earlier work. Git history remains the ultimate record of prior paths and revisions.
