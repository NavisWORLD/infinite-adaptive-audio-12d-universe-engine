# 📦 Download COSMOS Music

Want the app instead of the source code?

Go to the repository's **Releases** section and choose your device:

- **Windows** → download the `Windows-x64-Setup.exe`
- **Mac Apple Silicon** → download the `macOS-arm64.dmg`
- **Mac Intel** → download the `macOS-x64.dmg`
- **Android** → download the `Android-Community.apk`
- **iPhone / iPad** → use the installable PWA path; native developers also get the Xcode project and compiled simulator app

For exact instructions, signing notes, and checksum verification, read:

➡️ [`COSMOS_MUSIC_SUITE/docs/DOWNLOADS.md`](./COSMOS_MUSIC_SUITE/docs/DOWNLOADS.md)

The full release pipeline is open source in:

➡️ [`.github/workflows/cosmos-music-release.yml`](./.github/workflows/cosmos-music-release.yml)
